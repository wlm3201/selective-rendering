# 选择性渲染 · Selective Rendering

一个客户端 Fabric 模组：拿上一根风弹（或你指定的任何物品）当魔杖，在世界里框出选区、挑出方块，然后让被选中的方块按你设定的程度变淡，直至完全消失——方便看穿墙体、检查机器内部、展示结构剖面。

移植自 [Lucidity](https://github.com/mypalsml/lucidity-mod)（作者 mypals/ml）的同名功能，针对 Minecraft **26.1.2** 的全新渲染架构重写。

---

## 特性

- **九种模式**：按选区内 / 选区外 / 不限位置，配合列表内 / 列表外 / 全部，覆盖你能想到的每一种组合。
- **0–100% 连续透明度**：不是「要么画要么不画」，50% 时方块半透明可见，100% 时彻底消失。
- **多条选区**：可以同时框选并叠加任意数量的区域，全部参与判定。
- **灵活的方块规则**：支持方块 ID、方块标签、以及带方块状态的精确匹配。
- **穿透效果是真的**：隐藏的方块会被移出遮挡图，所以你能真正看穿它；它背后的方块会亮起来，而不是留下一片黑。
- **覆盖所有渲染路径**：静态方块、流体（水/岩浆）、方块实体（箱盖、告示牌文字）、活塞推动中的方块、下落方块。
- **Sodium / ImmediatelyFast / Fabric Renderer API 自动适配**，装了就走对应路径，没装就不加载。
- **按键走原版控制界面**，可自由改键，不会被别的键位模组落下。
- 中英双语，跟随游戏语言设置。

## 安装

| 项目 | 要求 |
|---|---|
| Minecraft | 26.1.x |
| Fabric Loader | ≥ 0.19.0 |
| Java | ≥ 25 |

把 jar 放进 `.minecraft/mods` 即可。**本模组不需要 Fabric API。**

可选依赖（装了才有的功能）：

| 模组 | 作用 |
|---|---|
| YetAnotherConfigLib (YACL) | 打开图形化配置界面 |
| Mod Menu | 在模组列表里出现配置按钮 |
| Sodium | 自动切换到 Sodium 渲染路径 |
| ImmediatelyFast | 自动适配其批处理缓冲 |
| Fabric Renderer API | 自动适配其移动方块渲染路径 |

## 快速开始

1. 手里拿一根**风弹**（默认魔杖）。
2. **左键**点一个方块设为角点 1，**右键**点一个方块设为角点 2 —— 中间会出现白色选框。
3. 按住**左 Ctrl + 左键**点击任意方块，把这两个角点围成的区域加入选区（青色框）。
4. 按住**左 Ctrl + 滚轮**切换模式，看着方块一点点淡下去。

不想用鼠标点也可以：按 **V** 打开配置界面，模式、透明度、方块列表、选区都能在里面直接改。

## 操作方式

前提：**手里拿着魔杖**（主手或副手都行）。没拿魔杖时所有点击都是原版行为。

### 鼠标

| 操作 | 效果 |
|---|---|
| 左键点击方块 | 设置角点 1（显示为**红色**框） |
| 右键点击方块 | 设置角点 2（显示为**蓝色**框） |
| 选区键 + 左键 | 若准星所在位置已有选区 → 删除它；否则把两个角点围成的区域加入选区 |
| 选区键 + 右键 | 直接把**指着的那一格**加成 1×1×1 选区（若该位置已有选区则删除），不用先摆角点 |
| 方块列表键 + 左键 | 把准星处方块的**方块 ID** 加入/移出列表 |
| 方块列表键 + 右键 | 把准星处方块**连同它当前所有方块状态**加入/移出列表 |

> 手持魔杖时的这些点击会拦截原版的破坏/放置，这是有意的：魔杖不是用来挖方块的。
> 点到空气时什么也不会发生，不会误选到世界原点。

### 滚轮

| 操作 | 效果 |
|---|---|
| 左 Ctrl + 滚轮 | 在九种模式间循环切换 |
| 左 Alt + 滚轮 | 沿你的视线方向移动**当前选中的角点**（水平朝向，俯仰角超过 60° 时改为上下） |

> 滚轮固定绑在 **Ctrl / Alt 两个键本身**上，不会跟着上面两个按键的重绑定走——这是为了让手感与同类模组一致。

### 按键

在 **选项 → 控制 → 选择性渲染** 里可以改：

| 按键 | 默认 | 说明 |
|---|---|---|
| 选区 | 左 Ctrl | 配合点击增删选区 |
| 方块列表 | 左 Alt | 配合点击编辑方块列表 |
| 打开配置界面 | V | 需安装 YACL |

## 九种模式

滚轮按下面的顺序循环：

| 模式 | 隐藏的是 |
|---|---|
| 关闭 | 不隐藏任何东西 |
| 选区内·指定类型 | 在任一选区**内**，且在方块列表**里**的方块 |
| 选区内·非指定类型 | 在选区内，且**不在**列表里的方块 |
| 选区内·全部 | 选区内的每一个方块 |
| 选区外·指定类型 | 在选区**外**，且在列表里的方块 |
| 选区外·非指定类型 | 在选区外，且不在列表里的方块 |
| 选区外·全部 | 选区外的每一个方块 |
| 所有区域·指定类型 | 列表里的方块，无论在哪（黑名单） |
| 所有区域·非指定类型 | 列表之外的方块，无论在哪（白名单） |

**安全兜底**：如果当前模式需要方块列表但列表是空的，或者需要选区但一个选区都没加，模组**不会隐藏任何东西**。否则白名单模式配空列表会把整个世界抹掉，那没人想要。

## 方块列表规则语法

在配置界面里一行一条，或用魔杖点击自动添加（添加时会显示 `+ minecraft:stone` 这样的提示）：

| 写法 | 含义 |
|---|---|
| `minecraft:stone` | 单个方块（命名空间可省略，写作 `stone`） |
| `#minecraft:planks` | 方块标签，匹配标签内的所有方块 |
| `*` / `?` / `%` / `any` | 任意方块（配合状态使用） |
| `minecraft:furnace[lit=true]` | 带方块状态的精确匹配 |
| `#minecraft:planks[axis=x]` | 标签 + 状态 |
| `[waterlogged=true]` | 只看状态，不看方块类型 |

规则是在匹配时才去解析状态属性的，所以给标签写状态时不用担心标签里各方块的属性不一致。写错的方块名或标签不会让整条规则消失，只是永远匹配不上——这样你在列表里还能看见它。

## 选区

- 两个角点围成的盒子**包含边角方块本身**（对角坐标会 +1）。
- 选区可以重叠：一个位置被多个选区覆盖时，仍然算「在选区内」。
- 删除选区时，**覆盖该位置的所有选区**都会被删掉。
- 角点 1 红、角点 2 蓝，**当前被滚轮选中的那个角点会带半透明填充**。
- 设置角点后它自动成为「选中的角点」，直接用 Alt + 滚轮就能微调，不用再声明是哪个。
- 已添加的选区显示为**青色实心框**；放下魔杖后所有框自动消失。

选区在配置界面里以文本 `x1,y1,z1:x2,y2,z2` 列出（和 Lucidity 的格式一致，可以互相复制）。世界里点出来的会列在这里，在这里改的也会在世界中生效。两个角点顺序任意，保存时会自动归一化。

---

## 透明度

0% = 完全不隐藏，100% = 完全消失，中间值就是不同程度的半透明。

- 透明度的 alpha 是**烘焙进区块几何**的，改动后需要重新编译受影响的区块，通常瞬间完成；改动较大时（比如切换模式）会重建整个世界，可能有一两帧的停顿。
- 流体跟随它所在的方块：方块被隐藏，里面的水/岩浆一起变淡，不再需要单独设一个流体透明度。
- 隐藏方块**后面的方块会正常受光**（模组让光从邻居最亮的一侧穿过来），所以不会出现「挖空一片却全是黑的」的情况。真实光照数据不会被改动，关掉模组零成本。
- 方块实体（箱盖、告示牌文字等）会跟着变淡，但**文字、物品、名字标签保持清晰**——半透明的字没人看得清。

## 配置界面

按 **V**（默认）或经 Mod Menu 打开，需要安装 YACL。五个选项：模式、透明度、方块列表、选区、魔杖。

每一项的「重置」按钮都会回到模组的**出厂默认值**，而不是你打开界面时的值。

没有安装 YACL 时按 V 会在聊天栏提示一句原因，不会静默失败。

### 配置文件

`config/selective_rendering.json`：

```json
{
  "version": 3,
  "mode": "OFF",
  "transparency": 50,
  "rules": ["minecraft:stone", "#minecraft:planks"],
  "regionPos1": [0, 64, 0],
  "regionPos2": [10, 70, 10],
  "regions": [[0, 64, 0, 10, 70, 10]],
  "wand": "minecraft:breeze_rod"
}
```

- `rules` 在旧版本里叫 `blocks`，读档时会自动迁移。
- `wand` 填任意物品 ID；填错或填空的会退回风弹，不会让你失去控制方式。

## HUD

手持魔杖时，左下角显示：

- 第一行：当前模式
- 第二行：两个角点坐标（只有需要选区的模式才显示）
- 下面：当前按住的键对应的操作提示

**没按任何键时列出全部操作；按住某个键时只显示这个键能做的事**——同样的信息，但不会在键盘上手忙脚乱时糊一屏。

修改方块列表后，屏幕下方中间会短暂显示 `+ minecraft:stone` / `- minecraft:stone`（绿/红），两秒后淡出。它不走原版的 toast 系统，所以不会被任何预设关掉。

## 已知限制

- **实体与粒子模式尚未实现**（配置项已预留）。
- **选区剪切（crop）尚未实现**：用两个角点把已有选区切一刀的功能还没做，相关的右键操作目前不启用。
- 隐藏判定发生在**区块编译线程**上，改动列表/选区后要等区块重新编译才生效。
- 活塞推动中的方块，判定用的是它**原本的状态与位置**，所以一个方块被推着走的时候不会中途「变回来」。

## 构建

```powershell
.\gradlew.bat build
```

产物在 `build/libs/`。构建配置界面需要把 YACL 等放进运行时：

```powershell
.\gradlew.bat build -PconfigScreen
```

环境：JDK 25、Minecraft 26.1.2、Fabric Loader 0.19.5、Loom 1.17-SNAPSHOT（Gradle 9.5.1）。26.1 起 Minecraft 不再混淆，构建不做 remap，Fabric API / YACL / Mod Menu 默认只是 `compileOnly`。

### 自动构建与发布

仓库带两个 GitHub Actions 工作流：

| 工作流 | 触发 | 做什么 |
|---|---|---|
| `build.yml` | 推送到 main、PR、手动 | 编译并上传 `build/libs/*.jar` 为构建产物 |
| `release.yml` | 推送 `v*` 标签、手动 | 编译并在 GitHub Release 上附上 jar，自动生成发布说明 |

发布时改版本号只需推一个标签，jar 名和 `fabric.mod.json` 里的版本号都会跟着走：

```powershell
git tag v1.1.0
git push origin v1.1.0
```

也可以在 Actions 页面手动运行 `Release`，填一个版本号（如 `1.1.0`），它会自己创建 `v1.1.0` 标签和 Release。手动运行还能勾选 prerelease。不填版本号则用 `gradle.properties` 里的 `version`。
