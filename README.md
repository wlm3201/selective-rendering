# Selective Rendering（选择性渲染）

[English](README.en.md) | 简体中文

一个 Fabric 客户端 Mod：可按「范围 + 方块名单」将任意方块半透明化或隐藏。

移植自 [Lucidity](https://github.com/hotpad100c/lucidity2.0) 的 selective rendering（原作者 ryan100c，许可 CC-BY-NC-4.0），
针对 MC 26.1 ~ 26.3 的新渲染架构重写，以及对 Sodium / Indigo 的兼容。

---

## 功能

- **把方块变淡**：修改顶点alpha并移入半透明渲染层，保留几何和光照。
- **透明度**：0% = 不透明，100% = 彻底隐藏。
- **模式**：选区内外 × 名单内外，共 9 种模式。
- **反转**：变为只显示指定方块。
- **选区**：类似投影模组操作。
- **变化记录器**：记录发生方块/状态变化的区域。
- **预设**：保存当前"模式/透明度/方块/选区"以便切换。
- **夜视**：方块全亮并跳过光照计算。

## 用法

默认魔杖为 **旋风棒（breeze rod）**，拿在手上以激活操作，

### 鼠标操作

| 操作           | 效果                       |
| -------------- | -------------------------- |
| 左键           | 设置角点 1（红框）         |
| 右键           | 设置角点 2（蓝框）         |
| 选区键 + 左键  | 添加选区或移除现有选区     |
| 选区键 + 右键  | 用当前选区裁剪所有已存选区 |
| 方块键 + 左键  | 增删方块 id 规则           |
| 方块键 + 右键  | 增删带状态的方块的规则     |
| 左 Ctrl + 滚轮 | 循环切换模式               |
| 左 Alt + 滚轮  | 移动当前选中角点           |

### 快捷键

| 键       | 默认    | 作用                    |
| -------- | ------- | ----------------------- |
| 打开配置 | `X + V` | 打开配置界面            |
| 记录     | `N`     | 开始 / 结束录制方块变化 |

### 记录器

1. 先框好选区；
2. 按 `N` 开始录制；
3. 运行一遍机器；
4. 再按 `N` 结束录制。

- **列表模式**
  - **白名单**：只记录名单内的方块变化。
  - **黑名单**：排除名单内的方块变化。
- **记录应用**：
  - **新增**：把记录到的位置合并后加入选区列表。
  - **裁剪**：用记录到的位置裁剪现有选区。

### 配置

- **模式 / 反转 / 透明度**
- **方块列表**
- **选区列表**（格式 `minX,minY,minZ:maxX,maxY,maxZ`）
- **方块键 / 选区键 / 配置键**
- **记录方块 / 列表模式 / 应用模式 / 记录键**
- **魔杖**物品
- **夜视**
- **预设**：新建 / 切换 / 覆盖 / 删除

---

### 模式一览

| 模式                                    | 被淡化的方块             |
| --------------------------------------- | ------------------------ |
| `OFF` 关闭                              | 无                       |
| `REGION_INSIDE` 选区内                  | 选区内所有方块           |
| `REGION_INSIDE_LISTED` 选区内·名单内    | 选区内 **且** 在名单内的 |
| `REGION_INSIDE_UNLISTED` 选区内·名单外  | 选区内 **且** 在名单外的 |
| `REGION_OUTSIDE` 选区外                 | 选区外所有方块           |
| `REGION_OUTSIDE_LISTED` 选区外·名单内   | 选区外 **且** 在名单内的 |
| `REGION_OUTSIDE_UNLISTED` 选区外·名单外 | 选区外 **且** 在名单外的 |
| `BLACKLIST` 名单内                      | 整个世界内名单内方块     |
| `WHITELIST` 名单外                      | 整个世界内名单外方块     |

开启**反转**后，被淡化的方块变为上表的**补集**。

### 方块规则语法

```
minecraft:stone                      指定方块
stone                                省略命名空间
#minecraft:planks                    方块标签
*                                    通配（* / % / ? 均可）
[waterlogged=false]                  方块状态
*[moving=true]                       特殊伪状态，匹配移动中的方块
```
