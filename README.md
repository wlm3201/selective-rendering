# Selective Rendering · 选择性渲染

[English](README.en.md) | 简体中文

一个 Minecraft Fabric 客户端 Mod：可按「区域 + 名单」将指定方块 / 实体半透明化或隐藏。

## 使用

手持指定工具（默认为旋风棒）激活以下操作

| 操作          | 作用                          |
| ------------- | ----------------------------- |
| 左键          | 设置角点 1                    |
| 右键          | 设置角点 2                    |
| Shift + 左键  | 清除角点                      |
| 中键          | 选中角点或选区                |
| 选区键 + 左键 | 添加/移除指向区域             |
| 选区键 + 右键 | 用当前区域裁剪现有选区        |
| 操作键 + 左键 | 增删方块 / 实体               |
| 操作键 + 右键 | 增删带状态方块 / 带物品ID实体 |
| Ctrl + 滚轮   | 循环切换模式                  |
| Alt + 滚轮    | 移动当前选中的目标            |
| Ctrl + Z/Y    | 撤销 / 重做选区修改           |
| X + V         | 打开配置界面                  |

### 模式

| 规则            |
| --------------- |
| 关闭            |
| 选区内          |
| 选区内 & 名单内 |
| 选区内 & 名单外 |
| 选区外          |
| 选区外 & 名单内 |
| 选区外 & 名单外 |
| 名单内          |
| 名单外          |

### 配置

| 全局     | 说明                  |
| -------- | --------------------- |
| 渲染模式 | 淡化规则内的方块      |
| 模式反转 | 淡化规则外的方块      |
| 透明度   | 淡化方块的透明度      |
| 方块名单 | 全局淡化方块名单      |
| 增删名单 | 添加/移除方块的快捷键 |
| 增删选区 | 添加/移除选区的快捷键 |
| 撤销选区 | 撤销上一次选区修改    |
| 重做选区 | 重做上一次选区撤销    |
| 打开配置 | 打开配置界面的快捷键  |
| 操作工具 | 激活操作的物品        |
| 方块全亮 | 最大化方块亮度        |
| 穿透方块 | 准心忽略淡化方块交互  |
| 穿透实体 | 准心忽略淡化实体交互  |
| 记录方块 | 记录方块变化的区域    |
| 名单模式 | 只/不记录名单内方块   |
| 应用模式 | 将区域添加/裁剪到选区 |
| 启停记录 | 开始/停止记录的快捷键 |
| 选区     | 编辑或删除选区        |
| 预设     | 将配置存为预设        |

| 选区   | 说明                 |
| ------ | -------------------- |
| 方块   | 淡化选区额外名单方块 |
| 实体   | 淡化选区名单实体     |
| 粒子   | 淡化选区名单粒子     |
| 透明度 | 选区独立透明度       |
| 投影   | 将选区方块在别处渲染 |
| 合并   | 将区域并入其他选区   |
| 独立   | 将子区域独立为选区   |
| 删除   | 删除子区域           |
| 角点   | 修改子区域角点       |
